OVERVIEW:

Welcome to VibeMart, a responsive shopping site that allows users to explore a variety of products, add them to their cart, and view detailed information. This project is built using HTML, CSS, and JavaScript, showcasing fundamental web development skills.

Key Features:

1.Product Listings: Browse through a range of products with images, names, and prices.

2.Search Functionality: Easily search for products using a search bar.

3.Add to Cart: Add products to the cart with a simple button click, storing the cart data in the browser's local storage.

4.Responsive Design: The site is designed to be mobile-friendly, ensuring a good user experience across devices.

Technologies Used:

1.HTML: Structure and content of the web pages.

2.CSS: Styling and layout of the site.

3.JavaScript: Interactive features and cart functionality.

How to Use:

Note: First file should be open is VibeMart.html which is linked to all other pages.

1.Search for products using the search bar.

2.Click on "Add To Cart" to add items to your cart.

3.View the cart status at the top of the page.

Installation:

Clone the Repository: Begin by cloning the repository to your local machine. Open your terminal and run the following command: https://github.com/Dpavan71/VibeMart.git

No Additional Setup Required:

This project is entirely client-side and does not require any additional software installations, such as servers or databases. Simply open the index.html file in a browser to view and interact with the website.
